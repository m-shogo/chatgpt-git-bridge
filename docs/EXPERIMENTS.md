# Experiments

実験事実を残す。推測と混ぜない。

## EXP-001 — ChatGPT生成画像は次ターンで実ファイルとして取得できる

**Date:** 2026-08-11

### Result
PASS

### Evidence summary
- image generation後、生成PNGが会話の後続ターンでも `/mnt/data/...png` として取得できた。
- 再生成ではなく、元の生成ファイルを扱えた。

### Learning
「画像生成で応答が終了する」ことと「生成ファイルが失われる」ことは別。
後続ターンにhandoffできる。

## EXP-003 — ChatGPT → GitHub binary blob

**Date:** 2026-08-11

### Result
PASS for smaller image

### Method
1. local/generated bytesをbase64化
2. GitHub Git Data `create_blob(encoding=base64)`
3. `create_tree`
4. `create_commit`
5. branch ref update

### Validation
事前計算したGit blob SHAとGitHub `create_blob`の返却SHAが一致。

### Learning
GitHub connectorでもbinary asset自体は保存できる。
ただし数MB PNGをChatGPTツール引数としてbase64搬送するのは重い。

## EXP-004 — 再生成で同一画像を復元できるか

**Date:** 2026-08-11

### Result
FAIL for exact reproduction

### Learning
